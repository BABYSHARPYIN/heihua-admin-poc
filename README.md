# 智能问答平台 · 词条管理 POC

在线地址：https://babysharpyin.github.io/heihua-admin-poc/

当前产品规则以 `docs/term-model.md` 为准，验收记录见 `design-qa.md`。

## 功能

- 表单仅维护词条、释义、应用范围、状态。新增可添加多个词条输入项，忽略空项；每个词条各自生成独立记录。编辑仅维护当前一条。
- 新增、编辑的应用范围不提供全选；选择全局时禁用具体Agent，选择一个或多个Agent时禁用全局，取消已选项后可切换。列表筛选仍支持混合多选和全选，空选表示全部应用范围。
- 相同文本在不同应用范围可同时存在；范围有交集的已有记录或同批词条冲突时，全部处理后才能保存。
- 列表一行一条记录，列为词条、释义、应用范围、状态、召回次数、更新时间、操作人、操作。范围是纯文本。
- 释义摘要按字符截取前200字，超出部分以 `...` 结尾；编辑保留完整内容。
- 默认召回次数降序，同次数按更新时间降序。示例数据具有不同次数，新记录为0；编辑不重置次数。
- 操作人由当前 POC 操作上下文自动记录为「admin」，表单不采集人员信息。
- 变更记录从行内操作进入，严格按记录ID展示只读日志，同名不同范围记录相互隔离。
- 删除、停用确认沿用现网弹层，仅包含标题、确认句、取消和主按钮。
- Agent 词条增强默认开启，说明为「开启后，问答将依据已配置词条理解专业用语。」启用状态与Agent增强开关共同决定有效配置，同文本Agent配置优先。
- 知识库设置保持基本信息、公开性设置、文件更新三个页签，原现网外壳保留。

## CSV

表头：`词条,释义,应用范围,状态`。

导入时同一单元格多个词条以顿号分隔，各自生成记录并共享本行其他配置；多个范围以 `|` 分隔具体名称。导入预览校验全部通过后原子写入。导出每行一条记录，遵循当前筛选与排序；不导出运行指标或人员字段。

浏览器历史数据转换为精简结构，保留原ID、词条、释义、范围、状态、合法次数与时间；旧版本的额外维护字段不进入当前模型，历史快照同步转换。未知范围不扩大权限。

## 运行与验证

```bash
npm install
npm run serve
npm run lint
npm test
npm run test:ui
```

本地地址：http://127.0.0.1:4173/。本项目为纯前端POC，数据保存在当前浏览器。次数为展示指标，不提供独立查询演示或联网问答服务。有效配置规则通过领域函数与测试验证。

终态截图在 `docs/screenshots/records-final/`。现网样式依据在 `docs/screenshots/live/190/` 与 `docs/live-reference.md`，其他截图和早期方案仅作历史证据。
