# 知识库级别黑话配置 POC

按用户明确授权，在当前独立新目录开发、公开发布新仓库；已有两个 POC 仅下载 HTML、读取 Pages 配置，不修改。

采用小型静态站点：index.html + style.css + app.js + domain.mjs。无服务端、无构建依赖，浏览器 localStorage 保存演示词条、Agent 开关和变更记录。参考 org-admin-poc 的 CSS 变量和主要组件原样复用；新增的设置页布局遵循同一视觉。

入口为知识库、专业 Agent、黑话管理。知识库列表进入设置，包含基本信息、公开性设置、文件更新、黑话配置；黑话配置只显示和维护当前库词条，表单范围锁定。专业 Agent 配置的效果设置提供默认开启的黑话增强，与追问推荐、上传文件复用开关组件。轻量解析演示体现子范围优先全局、停用不生效、关闭不解析。

词条字段为规范名/规范编码、别名数组、释义、作用范围类型及目标、状态、更新时间。规范化去除首尾空白、全半角兼容、比较忽略大小写；同一具体范围中规范名和别名共用冲突空间，跨范围重名允许，用于覆盖。保存立即生效。

CSV 使用 UTF-8 BOM，可用 Excel 打开。表头：规范名/规范编码,别名,释义,作用范围,范围名称,状态。别名以 | 分隔；CSV 正确处理引号、逗号和换行。导入在同一弹层内上传或粘贴、预览逐行校验，任何错误先修复再原子写入。知识库导入不允许越出当前库。导出当前筛选全集。

身份：黑话管理+全局、仅本库可写（设备运维知识库）、仅查看、无权限。前端演示授权同时作用于入口、页签、写按钮及写入操作；不作为生产安全认证。

变更记录在轻量弹层展示，允许撤销最近一次词条变更，保留回滚记录。静态站点默认 main 源码分支，gh-pages 发布分支根目录发布。单元测试验证数据规则；浏览器测试验证用户流程、权限、导入导出及设置；线上 HTTP 200 并识别应用标题。
