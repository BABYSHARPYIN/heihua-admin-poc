# 通用词条模型

词条与知识库是 Agent 的并列信息源。词条只支持全局或指定 Agent，没有知识库词条页签、知识库范围、知识库词条导入或知识库词条权限。

```json
{
  "id": "term-id",
  "name": "隔离开关",
  "aliases": ["刀闸"],
  "definition": "具有明显断开点的设备。",
  "scope": {"type": "app", "id": "app-device"},
  "status": "enabled",
  "updatedAt": "2026-11-19T03:00:00Z"
}
```

全局范围为 `{"type":"global"}`。内部 `app` 表示指定 Agent，必须存在于 Agent 列表。面向现场工程师，编辑仅提供名称、别名、释义、作用范围和状态。名称、别名和释义沿用既有规范化规则，不增加场景、消歧、问法示例或补充属性字段，不显示重复预览。

列表、搜索和召回展示仅使用当前可维护信息。CSV 模板和导出为六列：词条名称、别名、释义、作用范围、Agent名称、状态。旧七列文件仍可导入；历史属性仅保留在本地数据和变更快照中，编辑其他字段不清除它们，新导出不包含历史属性列。

## 召回与范围展示

词条管理的召回弹层选择全局或 Agent；全局仅匹配全局，指定 Agent 同时匹配全局及该 Agent。对同一命中问法，Agent 词条优先。停用不参与召回。列表和召回结果的范围仅展示文字，不提供 Agent 跳转；范围选择和筛选不变。

召回测试不受 Agent 效果开关影响：它用于检查词条本身。词条增强开关仅表达 Agent 在实际问答中是否使用词条信息，不在 Agent 页面实现召回演练。

## 数据兼容

浏览器 v1 数据迁移到 v2：原编码作为「编码」普通属性；已知旧知识库范围转为旧演示中对应的 Agent，未知范围忽略，不扩大到全局。旧本库可写身份降为仅查看。迁移变更记录时同步转换前后快照，避免回滚重新生成旧范围。

原知识库范围与指定 Agent 范围合并后，已有数据可能出现同范围名称/别名冲突。迁移保留内容供用户修正，保存与导入统一执行新校验；初始示例已经按新范围去除冲突。

## 回归

领域测试覆盖范围合法性、历史属性兼容、名称/别名冲突、搜索、分页、召回优先级、六列CSV往返、原子导入和迁移。UI测试覆盖五项编辑、无属性或重复预览、原样式、三个知识库页签、无Agent召回区、具体Agent筛选、范围纯文本不跳转、权限、导入导出及回滚。
