# 词条模型与应用范围

```json
{
  "id": "term-id",
  "name": "隔离开关",
  "aliases": ["刀闸"],
  "definition": "具有明显断开点的设备。",
  "attributes": [{"name":"型号","value":"DS-1"}],
  "scopes": [{"type":"global"},{"type":"app","id":"app-device"}],
  "status": "enabled",
  "updatedAt": "2026-11-19T03:00:00Z"
}
```

词条应用范围为非空数组，可选全局、一个或多个现有 Agent，或混合选择。知识库不参与词条关系。属性为可选数组，属性名和值成对填写，同词条属性名不可重复；编码不作为一等字段。表单不包含人员信息。

## 校验和筛选

名称、释义、应用范围必填。同词条范围去重。两个词条的范围只要存在交集，就校验名称与别名重复；无交集可同名。全局和单个 Agent 是不同配置范围，混合配置保留每一项，不折叠或扩大。

列表筛选采用范围并集：命中任一已选范围即显示，同条词条只出现一次。未选择时显示全部；全选明确选择全局和所有 Agent，搜索选项不改变全选的集合。筛选与表单使用同一个组件，支持键盘、搜索、复选和空结果。

列表显示所有已选范围，以普通文本分隔；具体 Agent 支持跳转到基础信息页。全局无链接。更新时间保留，列表行内不使用标签或状态徽标。

## CSV 与迁移

CSV 表头为名称、别名、释义、可扩展属性、应用范围、状态。应用范围以 `|` 分隔具体名称。属性序列化为 JSON；逗号、引号、换行按 CSV 转义。导入同批和既有数据统一校验，全部通过才写入。

旧 CSV 表头通过兼容解析统一为应用范围，旧 Agent名称列转换为具体范围。旧浏览器单个 `scope` 转为 `scopes` 数组，编码转普通属性；已知历史知识库标识转原对应 Agent，未知范围丢弃且不扩大权限。变更记录及其前后快照同步迁移，回滚保留原数组范围。

Agent 仅提供词条增强开关及说明。当前 POC 不包含独立查询演示、入口或执行路径。

## 验证

模型测试覆盖范围必填、混选去重、交集冲突、属性校验、并集筛选、CSV 往返和旧数据迁移。界面回归覆盖搜索与全选、混合保存、持久化、Agent 跳转、简化确认、权限、导入导出、回滚及原知识库设置。
